# Fonts

Jost, SIL Open Font License 1.1 (text in `OFL-Jost.txt`), Copyright 2020 The Jost Project Authors, https://github.com/indestructible-type/Jost . Files `jost-latin.woff2` and `jost-latin-ext.woff2` are the variable (weight 300 to 700) subsets served by Google Fonts, downloaded on 2026-11-06 and self hosted. No other font is used. To change the font, edit `assets/css/fonts.css` and the two `--f-*` variables in `style.css`.
